# Worksheet P12

## Pertemuan 12

Proyek P11 dipindahkan ke Vue + Vite. Susunan `src/` dan tugasnya:

| Berkas | Tugas |
| --- | --- |
| `App.vue` | Menyusun halaman, memuat state kategori saat mulai, menyimpan perubahan, dan mengatur ulang filter. |
| `components/KepalaProfil.vue` | Menampilkan header halaman P11, termasuk judul, navigasi, dan pilihan tema. |
| `components/TombolFilter.vue` | Menampilkan tombol kategori dan mengubah kategori aktif. |
| `components/DaftarProyek.vue` | Menyaring dan menampilkan kartu proyek. |
| `components/FormKontak.vue` | Menampilkan form dan validasinya. |
| `data.js` | Menyimpan data profil dan proyek. |
| `state.js` | Menyimpan daftar proyek dan kategori yang sedang dipilih. |
| `simpanan.js` | Membaca, menyimpan, dan menghapus pilihan kategori di localStorage. |
| `api.js` | Salinan lapisan data P10, belum dipakai oleh halaman. |
| `main.js` | Mengimpor CSS dan memasang aplikasi Vue. |

Yang disimpan di browser hanya kategori filter aktif. Isi form, pilihan tema, token, kata sandi, dan data pribadi tidak disimpan.
